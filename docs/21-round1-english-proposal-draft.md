## 1. Skill summary

RightsGap NAS compares two intended uses of the same media and shows which documentary evidence supports, contradicts or leaves each use unresolved.

## 2. Users and problem

Small creative teams keep images, agreements and amendments in scattered NAS folders. A reusable image may become unsuitable evidence-wise when purpose, channel, territory or date changes; filenames cannot explain why.

## 3. Proposed solution

A read-only Markdown Skill connects selected assets to authorized documents, separates retrieved facts from effective assessments, and compares six dimensions. Missing evidence produces a precise documentary repair question, rather than reassurance or legal clearance.

## 4. Core interaction

Select a bounded asset/document set and describe editorial website use versus paid advertising. For one shared image, add an authorized amendment. Its quoted clauses can change purpose, territory and date assessments while an independent channel prohibition survives. The report asks: which authorized amendment explicitly replaces that prohibition? Unrelated rows retain their original evidence revision.

## 5. Difference and innovation

Proof-Carrying Scenario Delta explains what changed, whether its assessment changed, and the exact supporting or blocking clause. It preserves unchanged restrictions and exposes uncertainty instead of producing a generic contract summary or permission score.

## 6. NAS capabilities and placement

Planned native orchestration uses file-agent for bounded inventory and verified paths, then document-agent for per-file QA and source context. NAS holds the team's existing media and documents; the Skill returns its report in chat.

## 7. Architecture, permissions and models

The parent delegates only to registered experts owning documented ug-filesystem find/stat/optional sha256sum and ug-document qa. Inputs include explicit roots, selected files, mappings, party and two scenarios. Reads require authorization; saving is disabled. The configured Uliya model route requires user acceptance. Cloud routing is possible; synthetic-only DeepSeek studies remain separate development proxies.

## 9. Finalist validation
