# 01 — Product brief

**Working name:** RightsGap NAS V3 — Evidence-Driven Media Reuse Planner
**Track candidate:** Unleash Your Creativity.
**Status:** Proposed, subject to technical go/no-go.

## User and job

An independent photographer, freelance designer, boutique studio or small nonprofit media manager has a UGREEN NAS holding original or licensed media plus scattered license/release PDFs. They want to reuse assets in a new context without assuming a prior license applies.

The precise job: *Before repurposing five campaign photos for another client/channel/region/date, show which statements have source evidence, which contradict explicit conditions, and which still require human confirmation.*

## Core product outcome

RightsGap creates a **Proof-Carrying Scenario Delta** from one authorized media/document scope and two use scenarios. It explains differences with actual source evidence and provides an **Evidence Repair Checklist**. The user can add a supplemental document and request an on-demand recheck.

## MVP user flow

1. Confirm a narrow asset folder, document folder, explicit asset-to-document mappings when needed, and the licensee identity.
2. Specify Scenario A and Scenario B, each with purpose, channel, territory and intended date.
3. Request bounded discovery and document QA through supported NAS expert agents.
4. Build a per-asset field matrix. Every positive field must have a source path and clause actually returned by an expert; incomplete evidence remains unresolved.
5. Compare A/B. Describe changed conclusions and their causes without automatically resolving conflicting amendments.
6. Output the scope receipt, evidence gaps and precise human follow-up questions.
7. Optionally, after explicit approval and verified capability, save a new review report; no file movement or publication.
8. Recheck on request after user adds evidence. Nothing runs as an unverified background service.

## Boundaries

One project; 5–8 assets; 3–6 documents; at most two scenarios per request; image/media and document formats only as officially supported. No image-to-person identity recognition, image copyright authentication, legal verdicts, automatic rights enforcement, unsolicited external API, background watchers or unauthorized scripts.

## Success demo

Same NAS photos and original licenses:

- Scenario A: NZ editorial website, 2026.
- Scenario B: worldwide paid digital advertising, 2027.
- Show a source-linked change for at least one clearly constrained asset, one unchanged status, and one unresolved asset.
- Optionally add a synthetic amendment and recheck without rewriting unrelated rows.

All demo assets and documents must be original, synthetic or properly licensed; never expose real users' private data.

## Why a UGREEN NAS Skill?

It uses user-authorized resident files, metadata and source documents through the supported UGOS experts. NAS is the working data repository, not an unrelated application host. Any claim that processing is wholly offline remains **Unknown** until model configuration and the assigned NAS runtime are verified.

## What we deliberately do not claim

"Evidence-consistent for evaluated fields" is not the same as "licensed" or "legally safe." Copyright, publicity, privacy, contractual and other third-party restrictions may remain unassessed.
